1 First 5 Minutes — From Installation to First Macro Activation

d4cute helper is a high-performance assistant that comfortably and safely helps with repetitive skill casting, buff maintenance, and complex inventory transmogrification of the Horadric Cache while playing Diablo 4.

  1. Download Latest Installer — Download and install the installer (d4cute_helper_setup.exe), or run the portable executable (d4cute_helper.exe) directly. If Windows displays an "Unknown publisher" warning, click More info → Run.
  2. When the helper is launched, the window automatically starts at its smallest default size, so it doesn't obstruct the game screen.
  3. From the profile bar, select a profile appropriate for your class, or create a new one with the ＋ button.
  4. Press slot A, then in Macro Settings, click the blue activation key button, and assign the mouse or keyboard key you want to use.
  5. In the Sequence tab, add skill keys and delays to cast, or press the Record button to record actual in-game key inputs.
  6. Press the ▶ Start button at the bottom, return to the game, and press the activation key for the macro to operate safely.
🛡️
Game Window Activation Detection: The helper only sends keyboard/mouse input to the game when the Diablo 4 window is active. Input automatically stops when you are on the desktop or working in other windows.
🖥️
Game Screen Mode: Set Diablo 4's display settings to Windowed Fullscreen or Windowed Mode. In Exclusive Fullscreen, overlays may not be visible and transmogrification screen reading may fail.

3 Macro Settings — Execution Method · Activation Method · Activation Key

1) Execution Method and Activation Method

Category Mode Name Description and Recommended Use
Execution Method Sequential Casts from Step 1 to the last step in order, then repeats from the beginning. Suitable for fixed skill combos and damage cycle rotations.
Independent Each step independently repeats according to its own configured cooldown (wait time). Optimized for maintaining shield/buff skills with varying cooldowns.
Activation Method Hold The macro runs only while the activation key is held down, and stops immediately when the key is released. Recommended for primary damaging skills.
Toggle Pressing the activation key once turns it on, and pressing it again turns it off. Reduces finger fatigue during long farming sessions or dungeon runs.
Once Pressing the activation key executes the sequence once from beginning to end and then stops automatically. Suitable for consecutive potion crafting, equipment purchasing, etc.

2) Activation Key Selection and Fine-Tuning

  • Flexible Activation Keys: Supports all keyboard keys, mouse left/right click, scroll up/down, side buttons, and Ctrl · Shift · Alt combination keys. You can assign the same activation key to multiple slots for simultaneous activation. However, it cannot overlap with convenience feature (transmogrification) start hotkeys — it will be rejected upon selection.
  • Press Delay: Ignores short, quick clicks, and only activates the macro when the key is held down for longer than the specified time (e.g., 250~300ms). This is an **essential setting to prevent inventory or stash windows from closing when using right-click as the activation key**.
  • Release Buffer: Extends macro operation for a specified duration even after the activation key is released. Provides a buffer to ensure attacks don't stop while looting nearby floor items immediately after combat.
  • Companion Keys: You can specify keys to be continuously held down together while the macro is active (e.g., Shift for forced stationary attack, forced movement keys, etc.).

2) Real-time Mouse Coordinate Recording and Humanized Random Error

  • When you press the Record button and input keys and mouse movements on the game screen, the sequence and time intervals are recorded exactly as they are.
  • Screen Coordinate Recording: When you click the mouse, the absolute coordinates (X, Y) of the clicked screen position are recorded, and the macro automatically clicks that position during playback.
  • Humanized Random Error:
    • Click Position ± px: Introduces irregular errors within a specified pixel radius for each click to prevent mechanical detection.
    • Random Variation %: Incorporates a certain percentage of random delay for each step interval to mimic natural hand movements.

3) Drag Path Recording — Including the Path Moved While Pressed (1.32.0)

  • During recording, if you move while holding down the mouse button, that path is also recorded. Coordinates are recorded whenever you move more than 8px or 16ms passes from the last recorded point, ensuring fast rotations are densely captured and slow movements are smoothly continuous.
  • During playback, the button is pressed at the initial click position, the cursor moves along the same path according to the recorded timing, and the button is released at the release position. Previous versions only remembered the press and release points, resulting in instant teleportation.
  • Channeling Skills like Whirlwind · Concentrate: If you assign a skill to the Right Mouse Button in-game and spin while holding down the right button during recording, that rotation will be recorded and replayed exactly. The same applies to moving while holding down the left button.
  • Random Variation % is applied once for the entire path duration, and Click Position ± px is applied once for the entire path, so the cursor does not shake.
  • If you edit the position by value in the step editor or press Clear Drag, the path is discarded, and playback jumps as in previous versions.
  • Up to 600 points are saved per drag (approximately 10 seconds at 16ms intervals). Since paths use absolute screen coordinates, re-record if you change the resolution or window position.

5 Utility Features — Inventory Transmutation (Single-Page UI)

The **Inventory Transmutation tool**, newly revamped in version 1.30, automates the process of transmuting legendary and unique items using the Horadric Cube with just a few operations.

🔍 Click to enlarge
📷 Utility Feature: Horadric Cube Inventory Transmutation Single-Page UI

1) 33-Slot Automatic Grid Calculation and Start

  1. In the game, open the **Inventory** and **Horadric Cube** windows.
  2. Click Select First Slot, then hover your mouse over the very first slot (top-left) of your in-game inventory and press Enter.
  3. Click Select Last Slot, hover your mouse over the very last slot (bottom-right) of your inventory, and press Enter. (Press Esc anytime to cancel)
  4. By simply specifying the positions of these two points, the center coordinates for all 33 inventory slots will be automatically and accurately calculated.
  5. Pressing the start hotkey (default F10, can be changed by clicking the blue key button) on the game screen will automatically begin the transmutation process. The hotkey operates continuously even if the utility features tab is not open.

2) Operation Mechanism and Intelligent Safety Features

  • Intelligent Loop Cycle: Automatically cycles through each inventory slot, performing Right-click → Place in Horadric Cube → Click Transmute Item button → Transform → Accept (Enter) → Reset.
  • Skip Bound Items Switch: When the switch is on, it skips bound items and only transmutes unbound equipment. When the switch is off, it also transmutes bound items and safely sends Enter only when the acceptance pop-up window appears.
  • Cube Empty Check: After resetting, it checks if the first slot of the cube is empty by its **image** (remembering empty/filled states when placing the first item). In environments where the image cannot be detected, it uses the cube header text for secondary verification. If it's not empty, it tries resetting again; if it still isn't empty, it stops — this mechanism prevents two items from stacking in the cube.
  • Emergency Stop: During operation, pressing the Esc key on the keyboard will immediately stop the transmutation process, no matter where you are.
  • Slow PC Adjustment Values: ms before start (grace period to switch to the game window after clicking start), ms for result wait (default 3000 — upper limit to wait for transmutation to finish and the transmute button to become inactive after transform/accept; proceeds immediately if signal is received), ms after reset (default 0 — additional wait after reset). If items overlap or are skipped without transmuting on a slow PC, increase the result wait time.
  • Execution Log: After each cycle, slot-by-slot judgments are logged in %APPDATA%\d4cute_helper\debug\alter_slots.txt. If you encounter any issues, please upload this file to the Telegram group.

12 Frequently Asked Questions (FAQ) & Troubleshooting

Q. My skills don't activate when I press the trigger key.

  • Check if the status on the top bar is Running (whether the ▶ Start button has been clicked).
  • Check if the macro activation switch for the selected slot is turned on, and if there is at least one step in the sequence tab.
  • The Diablo 4 game window must be focused in the foreground.
  • If you have chat or inventory open and the helper is paused due to the Pause Key, pressing the trigger key once more will unpause it.

Q. I use the right mouse button as the trigger key, but windows keep closing in my inventory or stash.

Set the Press Delay in the macro settings to 250ms ~ 300ms. This way, a 'short click' when right-clicking to move items will be passed directly to the game, and the macro will only activate when you hold down the button, completely eliminating accidental window closures.

Q. The Horadric Cube's Transmutation button isn't found or it stops.

In version 1.30, the OCR text recognition logic and cube emptiness verification have been significantly enhanced. If text is too blurry or UI scaling is extreme in your in-game graphics settings, recognition may be difficult. If the issue persists, please copy the alter_slots.txt file from the %APPDATA%\d4cute_helper\debug\ folder and inquire in the Telegram group.

Q. In Transmutation, two items overlap, or it moves to the next slot without transmuting.

This symptom occurs on PCs where the transmutation animation is slow. Increase the Result Wait ms in the Convenience Features tab (e.g., 3000 → 5000). If it still repeats, please upload debug\alter_slots.txt to the group. Starting from 1.30.1, it checks if the first slot of the cube is empty using an image and presses Enter even if the acceptance window appears late.

Q. Where can I ask helper/macro questions?

They are only accepted in the Telegram user group @d4cute_helper. The Uncle Anjandaing YouTube channel is a game streaming channel and does not accept helper/macro inquiries.

Q. The window appears white or flickers (white screen phenomenon).

In 1.30, the renderer of the embedded browser was changed to fix the white screen issue. If it reappears, please upload the Copy Errors Only result from the log viewer and a screenshot to the Telegram group.
