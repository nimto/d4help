1 The First 5 Minutes — From Installation to Your First Macro

d4cute helper is a high-performance assistant that comfortably and safely supports repetitive skill casting, buff upkeep, and complex Horadric Cube Stat Alteration work in Diablo IV.

  1. Download the latest installer — get the installer (d4cute_helper_setup.exe) and install it, or run the portable executable (d4cute_helper.exe) directly. If Windows shows an "Unknown publisher" warning, click More info → Run anyway.
  2. When you launch the helper, the window automatically starts at the smallest default size so it does not cover the game screen.
  3. On the profile row, select the profile that matches your class, or create a new one with the ＋ button.

3 Macro Settings — Run Mode · Trigger Type · Trigger Key

1) Run Mode and Trigger Type

Category Mode Description & recommended use
Run Mode Serial Casts from step 1 to the last step in order, then repeats from the beginning. Suited to fixed skill combos and damage cycle rotations.
Async Each step repeats independently on its own cooldown (wait time). Optimized for keeping up shield/buff skills that all have different cooldowns.
Trigger Type Hold The macro runs only while you hold the trigger key and stops immediately when you release it. Recommended for main damage skills.
Toggle Press the trigger key once to turn it on and again to turn it off. Reduces finger fatigue during long farming or dungeon runs.
Once Pressing the trigger key runs the sequence once from start to finish and then ends by itself. Suited to continuous potion crafting, equipment purchases, and the like.

2) Choosing a Trigger Key & Fine Tuning

  • Flexible trigger keys: Supports every keyboard key, left/right mouse click, wheel up/down, side buttons, and Ctrl · Shift · Alt combination keys. You can assign the same trigger key to several slots to trigger them together. However, it cannot overlap with the Tools (Stat Alteration) start hotkey — an overlap is rejected when you pick it.
  • Press Delay: Quick taps are ignored, and the macro turns on only when the key is held for at least the specified time (e.g. 250~300ms). An essential setting to prevent the inventory or stash window from closing when you use right-click as the trigger key.
  • Release (keep running after release): Keeps the macro running for the specified time even after you release the trigger key. This gives you leeway so attacks do not stop while you loot nearby items on the ground right after hunting.
  • Companion Keys: You can specify keys that are held down continuously while the macro runs (e.g. the stand-still attack key Shift, the force-move key, and so on).

2) Real-Time Mouse Coordinate Recording & Humanizing Random Variance

  • Record Press the button, then enter keys and mouse input in the game screen, and the order and time intervals are recorded exactly as they happen.
  • Screen coordinate recording: When you click the mouse, the absolute screen coordinates (X, Y) of that click are recorded, and the macro automatically clicks that position on playback.
  • Humanizing random variance:
    • Click position ± px: Adds an irregular offset within the specified pixel radius on every click to prevent mechanical detection.
    • Random variance %: Mixes a random delay of a set percentage into each step interval to imitate natural hand movement.

3) Drag Path Recording — Including the Path You Move While Holding (1.32.0)

  • If you move the mouse while holding a button down during recording, that path is recorded too. A point is written each time you move 8px or more from the last recorded point, or when 16ms has passed, so fast rotations stay dense and slow movements stay unbroken.
  • On playback, the button is pressed at the pressed position, then the cursor moves along the same path at the recorded times , and the button is released at the release position. Previous versions remembered only two points (press and release) and jumped instantly.
  • Channeling skills such as Whirlwind · Concentration: In the game, put the skill on the right mouse button, and while recording, hold the right button and circle around — that rotation is recorded and replayed exactly. Moving while holding the left button works the same way.
  • Random variance % is applied once over the whole path duration, Click position ± px is applied only once over the whole path, so the cursor does not shake.
  • In the Step Editor, you can edit the positions numerically, or Clear Dragto discard the path and go back to jump playback as before.
  • Up to 600 points are stored per drag (about 10 seconds at 16ms intervals). The path uses absolute screen coordinates, so re-record it if you change the resolution or window position.

2) Operating Mechanism & Smart Safety Features

  • Smart repeat loop: Goes through each inventory slot and automatically proceeds through right-click → place on the Horadric Cube → click the item Transmute button → Transmute → Accept (Enter) → Reset.
  • Skip Account Bound Items switch: When the switch is on, bound items are skipped and only unbound gear is altered. When it is off, bound gear is altered as well, and it safely sends Enteronly when the accept popup window appears.
  • Cube Empty Check: After a reset, it checks whether the cube is empty using the cube's first-slot image(it remembers how the slot looks empty and filled when the first item is placed), and where the image cannot be captured it uses the cube header text as a fallback. If the cube is not empty, it presses Reset again, and stops if it never empties — a safeguard to prevent two items from being placed on top of each other.
  • Emergency stop: While it is working, press the keyboard's Esc key to stop Stat Alteration immediately from anywhere.
  • Slow-PC adjustment values: Start Delay ms(time to switch to the game window after pressing Start), Result Wait ms(default 3000 — the maximum time to wait after Transmute/Accept until the alteration finishes and the Transmute button turns off; it moves on immediately once the signal arrives), Post-reset ms(default 0 — extra wait after a reset). On a PC with slow animations, if items overlap or it moves on without altering, raise Result Wait.
  • Run log: Every time it finishes one pass, %APPDATA%\d4cute_helper\debug\alter_slots.txt keeps the per-slot results. If a problem occurs, please post this file to the Telegram group.

12 Frequently Asked Questions (FAQ) & Troubleshooting

Q. I press the trigger key but the skill does not fire.

  • Check that the top bar's status shows Running(whether you clicked the▶ Start button).
  • Check that the selected slot's macro active switchis on, and that at least one step is in the Sequence tab.
  • The Diablo IV game window must be focused at the very front of the screen.
  • If you opened chat or the inventory and it is paused by a pause key, press the trigger key once more to release it.

Q. I use right mouse as the trigger key, but the window keeps closing in the inventory or stash.

In the macro settings, set Press Delayto 250ms ~ 300ms. This way the 'short click' you make when right-clicking items to move them passes through to the game as is, the macro turns on only when you press and hold, and the window-closing malfunction disappears completely.

Q. Horadric Cube Stat Alteration cannot find the button or stops.

Version 1.30 greatly strengthened the OCR text recognition logic and the Cube Empty Check. If the text in the in-game graphics settings is too blurry or the UI scale is extreme, recognition can be difficult, so if the problem continues, in the %APPDATA%\d4cute_helper\debug\ folder, copy the alter_slots.txt file and ask in the Telegram group.

Q. In Stat Alteration, two items overlap, or it moves on to the next slot without altering.

This happens on PCs where the alteration animation is slow. In the Tools tab, raise the Result Wait ms(e.g. 3000 → 5000), and if it still repeats, post debug\alter_slots.txt to the group. Since 1.30.1, it checks that the cube is empty using the cube's first-slot image and presses Enter even if the accept window shows up late.

Q. Where do I ask helper/macro questions?

Telegram user group @d4cute_helper is the only place we take them. The 삼촌안잔다잉 YouTube channel is a stream for enjoying the game, so it does not accept helper/macro inquiries.

Q. The window turns white or flickers (whiteout).

Version 1.30 fixed the whiteout by changing the embedded browser's renderer. If you still see it again, post the log viewer's Copy Errors Only result and a screen capture to the Telegram group.
