1 Unang 5 Minuto — Mula sa Pag-install hanggang sa Unang Macro

Ang d4cute helper ay isang mataas na performance na katulong na ligtas at maayos na tumutulong sa Diablo IV sa paulit-ulit na pag-cast ng skill, pagpapanatili ng buff, at nakakapagod na Stat Alteration ng imbentaryo gamit ang Horadric Cube.

  1. I-download ang Pinakabagong Installer — I-download at i-install ang installer (d4cute_helper_setup.exe), o direktang patakbuhin ang portable na executable file (d4cute_helper.exe). Kung magpakita ang Windows ng babalang "Unknown publisher", pindutin ang More info → Run anyway.
  2. Kapag binuksan ang helper, awtomatikong magsisimula ang window sa pinakamaliit na default na laki kaya hindi nito natatakpan ang screen ng laro.
  3. Sa profile bar, pumili ng profile na akma sa iyong class, o gumawa ng bago gamit ang ＋ button.
  4. Pindutin ang slot Aat sa Pag-set up ng Macro, pindutin ang asul na button ng trigger key, at itakda ang mouse o keyboard key na gagamitin.
  5. Sequence Sa tab na ito, magdagdag ng mga skill key at delay na ika-cast, o pindutin ang Record button para eksaktong i-record ang mga key input mo sa totoong gameplay.
  6. Sa ibaba, pindutin ang ▶ Start button, bumalik sa laro, at pindutin ang trigger key para gumana nang ligtas ang macro.
🛡️
Pagtukoy sa Aktibong Window ng Laro: Nagpapadala lang ang helper ng keyboard/mouse input sa laro kapag aktibo ang window ng Diablo IV. Awtomatikong humihinto ang input kapag nasa desktop o ibang window ka.
🖥️
Screen Mode ng Laro: Itakda ang display setting ng Diablo IV sa Windowed (Fullscreen) o Windowed mode. Sa exclusive fullscreen, hindi makikita ang overlay at maaaring pumalya ang pagbabasa ng screen ng Stat Alteration.

3 Pag-set up ng Macro — Execution Mode · Trigger Mode · Trigger Key

1) Execution Mode at Trigger Mode

Kategorya Pangalan ng Mode Paliwanag at Inirerekomendang Gamit
Execution Mode Serial Nagca-cast nang sunod-sunod mula Step 1 hanggang sa huling step, at inuulit mula sa simula. Angkop sa nakatakdang skill combo at deal cycle rotation.
Async Bawat step ay paulit-ulit na tumatakbo nang hiwalay ayon sa sarili nitong cooldown (oras ng paghihintay). Pinakaangkop sa pagpapanatili ng shield/buff skills na magkakaiba ang cooldown.
Trigger Mode Hold Tumatakbo ang macro habang hawak mo lang ang trigger key at agad itong humihinto kapag binitawan mo ang key. Inirerekomenda para sa pangunahing damage skill.
Toggle Mag-o-on kapag pinindot nang isang beses ang trigger key at mag-o-off kapag pinindot ulit. Binabawasan ang pagod ng daliri sa matagal na farming o pag-ikot sa dungeon.
Once Kapag pinindot ang trigger key, isang beses nitong ginagawa ang sequence mula simula hanggang dulo at kusa itong humihinto. Angkop sa tuloy-tuloy na paggawa ng potion, pagbili ng gear, at iba pa.

2) Pagpili ng Trigger Key at Masusing Pag-tune

  • Flexible na Trigger Key: Sinusuportahan ang lahat ng key ng keyboard, kaliwa/kanang click ng mouse, wheel pataas/pababa, side button, at Ctrl · Shift · Alt mga kombinasyon ng key. Maaari mong itakda ang parehong trigger key sa maraming slot para sabay-sabay silang mag-trigger. Pero hindi ito maaaring mag-overlap sa start hotkey ng convenience feature (Stat Alteration) — tatanggihan ito sa pagpili kapag nag-overlap.
  • Press Delay: Binabalewala ang maiikling tapik na click, at nag-o-on lang ang macro kapag matagal na pinindot nang lampas sa itinakdang oras (hal. 250~300ms). Ito ay isang kinakailangang setting para maiwasan ang pagsara ng inventory o stash window kapag right-click ang gamit na trigger key.
  • Release Buffer: Pinahahaba ang pagtakbo ng macro sa itinakdang oras kahit nabitawan mo na ang trigger key. Binibigyan ka nito ng palugit para hindi maputol ang atake habang nagla-loot ng mga item sa sahig pagkatapos manghuli.
  • Companion Keys: Maaari kang magtakda ng mga key na patuloy na pinipindot kasabay habang tumatakbo ang macro (hal. stand-still attack key Shift, force move key, at iba pa).

4 Sequence Builder · Bulk na Pagpapalit ng Delay · Pagre-record ng Mouse

1) Step Card at Bulk na Operasyon

  • Kapag nag-click ka sa step card, maaari mong palitan nang paisa-isa ang key, action mode, at delay (oras ng paghihintay, ms).
  • Mga Opsyon sa Mode:
    • Single: Isang beses na input ng key
    • Burst: Mabilis na pag-tap sa itinakdang pagitan
    • Hold: Hawak ang key sa loob ng itinakdang oras
  • Bulk na Pagpapalit ng Delay: Pinapalitan nang sabay ang oras ng paghihintay ng lahat ng step sa nais na halaga (ms) o porsyento (%).
  • Lahat → Burst/Single: Isang click para palitan ang action mode ng lahat ng nakarehistrong step.
📷 Window ng Pag-edit ng Isang Step
📷 Popup ng Bulk na Pagpapalit ng Delay

2) Real-time na Pagre-record ng Coordinate ng Mouse at Humanized na Random na Pagkakaiba

  • Record Pindutin ang button, pagkatapos ay mag-input ng key at mouse sa screen ng laro, at mare-record nang buo ang pagkakasunod-sunod at pagitan ng oras.
  • Pagtatala ng Coordinate ng Screen: Kapag nag-click ang mouse, nare-record ang absolute coordinate (X, Y) ng screen na na-click, kaya awtomatikong kinaki-click ng macro ang lugar na iyon sa playback.
  • Humanized na Random na Pagkakaiba:
    • Posisyon ng Click ± px: Sa bawat click, nagbibigay ng hindi regular na pagkakaiba sa loob ng itinakdang radius ng pixel para maiwasan ang mekanikal na pagtukoy.
    • Random na Pagbabago %: Hinahaluan ng random na pagkaantala na may tiyak na porsyento ang bawat pagitan ng step para gayahin ang natural na galaw ng kamay.

3) Pagre-record ng Drag Path — Pati ang Landas ng Paggalaw habang Nakapindot (1.32.0)

  • Habang nagre-record, kapag ginalaw mo ang mouse nang nakapindot ang button , mare-record din ang landas na iyon. Mula sa huling record point, nagtatala ng coordinate kapag lumampas sa 8px ang galaw, o kapag lumipas ang 16ms , kaya siksik ang rekord ng mabilis na pag-ikot at tuloy-tuloy ang mabagal na galaw.
  • Sa playback, pinipindot ang button sa lugar kung saan ito pinindot, ginagalaw ang cursor sa parehong landas ayon sa nakatalang oras, at binibitawan sa lugar kung saan ito binitawan. Sa naunang bersyon, dalawang punto lang (lugar ng pagpindot at pagbitaw) ang naaalala kaya biglang lumilipat ang cursor.
  • Mga channeling skill tulad ng Whirlwind · Concentration: Ilagay ang skill sa laro sa kanang button ng mouse, at kung iikot mo ito habang nakapindot ang kanang button sa pagre-record, mare-record at mape-playback ang pag-ikot nang buo. Pareho rin ang paggalaw habang nakapindot ang kaliwang button.
  • Random na Pagbabago %ay inilalapat nang isang beses sa buong oras ng landas, Posisyon ng Click ± pxay inilalapat nang isang beses lang sa buong landas kaya hindi nanginginig ang cursor.
  • Kapag itinama mo ang posisyon gamit ang numero sa step editor, o pinindot mo ang I-clear ang Drag, itatapon ang landas at magpe-playback ito ng paglukso gaya ng dati.
  • Hanggang 600 punto ang sine-save sa isang drag (mga 10 segundo kung 16ms ang pagitan). Absolute screen coordinate ang landas, kaya i-record ito ulit kung binago mo ang resolution o posisyon ng window.

🔧 Paano Gamitin ang Rotation Pack at Mga Tip sa Setting

  1. Pag-import (Import): Mula sa Telegram, i-download ang sequences.d4seq file, at sa ibaba ng helper window, pindutin ang Mag-import button, pumili ng file, at mairerehistro nang sabay ang 9 na sequence.
  2. Pag-assign sa Slot: Pindutin ang macro slot na gusto mo (A~G), at sa Sequence Library, piliin ang paborito mong preset sa 9 na nasa itaas.

5 Mga Convenience Feature — Stat Alteration sa Imbentaryo (Isang Pahinang UI)

Ang bagong inayos sa bersyon 1.30 na Inventory Stat Alteration Toolay nag-a-automate ng Stat Alteration ng Legendary at Unique gear gamit ang Horadric Cube sa ilang operasyon lang.

🔍 I-click para palakihin
📷 Mga Convenience Feature: Isang Pahinang UI ng Stat Alteration sa Imbentaryo gamit ang Horadric Cube

1) Awtomatikong Pagkalkula ng 33-Slot Grid at Pagsisimula

  1. Sa laro, buksan ang Inventoryat ang Horadric Cube window.
  2. Pumili ng Unang Slotbutton, pagkatapos ay ilagay ang mouse sa pinakaunang slot (kaliwang itaas) ng imbentaryo sa laro, at pindutin ang Enter.
  3. Pumili ng Huling Slotbutton, ilagay ang mouse sa pinakahuling slot (kanang ibaba) ng imbentaryo, at pindutin ang Enter. (Para kanselahin anumang oras, pindutin ang Esc)
  4. Kapag naitakda mo lang ang posisyon ng dalawang punto, awtomatiko at tumpak na makakalkula ang center coordinate ng 33 slot ng imbentaryo.
  5. Sa screen ng laro, pindutin ang start hotkey (default: F10, maaaring palitan sa pagpindot sa asul na key button) at magsisimula nang buong awtomatiko ang Stat Alteration. Palaging gumagana ang hotkey kahit hindi nakabukas ang tab ng mga convenience feature.

2) Mekanismo ng Operasyon at Matalinong Safety Feature

  • Matalinong Paulit-ulit na Loop: Iniikot ang bawat slot ng imbentaryo at awtomatikong isinasagawa ang Right-click → ilagay sa Horadric Cube → i-click ang button ng pagbabago ng item → Transform → Accept (Enter) → Reset.
  • Switch sa Paglaktaw ng Account Bound Items: Kapag naka-on ang switch, nilalaktawan ang mga bound item at hindi-bound na gear lang ang pinipili at binabago. Kapag naka-off, pati bound gear ay binabago, at ligtas na ipinapadala lang ang Enterkapag lumabas ang accept popup window.
  • Pag-verify na Walang Laman ang Cube (Cube Empty Check): Pagkatapos ng reset, sinusuri kung walang laman ang unang slot ng cube gamit ang larawan(natatandaan nito ang hitsurang walang laman at may laman noong inilagay ang unang item), at sa kapaligirang hindi mahuli ang larawan, tumutulong ang pagbasa sa teksto ng header ng cube sa paghatol. Kapag hindi walang laman, pipindutin ulit ang reset, at kung hindi pa rin nawalan ng laman, hihinto ito — isang safeguard ito para hindi magpatong ang dalawang item.
  • Emergency Stop: Habang gumagana, kapag pinindot mo ang keyboard key na Esc saanman, agad na hihinto ang Stat Alteration.
  • Mga Setting para sa Mabagal na PC: Delay Bago Magsimula (ms)(palugit para makalipat sa window ng laro pagkatapos pindutin ang start button), Paghihintay sa Resulta (ms)(default 3000 — pinakamataas na paghihintay hanggang matapos ang pagbabago pagkatapos ng transform at accept at mamatay ang transform button; lilipat agad kapag dumating ang signal), Delay Pagkatapos ng Reset (ms)(default 0 — karagdagang paghihintay pagkatapos ng reset). Kung nagpapatong ang mga item o nilalaktawan ang pagbabago sa PC na mabagal ang animation, dagdagan ang paghihintay sa resulta.
  • Talaan ng Takbo: Sa bawat ikot, %APPDATA%\d4cute_helper\debug\alter_slots.txt ay nag-iiwan ng hatol para sa bawat slot. Kapag may problema, i-upload ang file na ito sa Telegram group.

6 Smart Alarm System — Event · Personal · Alerto sa Screen · Boses (TTS)

Isa itong mataas na performance na background alarm engine na nagpapaalala para hindi mo makaligtaan ang mga pangunahing time-based na content ng Diablo IV (Legion invasion, World Boss, Helltide, at iba pa) at ang sarili mong mga timer.

1) Mga Abiso ng Event (World Boss · Helltide · Legion)

Real-time na nakakonekta sa website sa labas ng laro (diablo4.life) at awtomatikong kinakalkula ang pinakabagong oras ng paglitaw ng boss at Helltide.

🔍 I-click para palakihin
📷 Mga Abiso ng Event (iskedyul ng World Boss, Helltide, Legion at oras ng abiso)
  • Pagpili ng Oras ng Abiso: Para sa bawat event, maaari mong i-on at i-off nang hiwalay ang oras na 5 min, 3 min, 1 min bago magsimula at ang oras ng pagsisimula .
  • Pagkakasunod-sunod ng Priyoridad Kapag Nag-overlap: ▲ ▼ Pindutin ang mga button para baguhin ang pagkakasunod-sunod ng mga event. Kung maraming abiso ang sabay na dumating sa parehong oras, ang event na nasa itaas ang unang tutunog at sabay-sabay na ipapakita sa screen.
  • Pagtatakda ng Anchor ng Legion: Maaari mo ring mano-manong i-adjust ang oras ng paglitaw ng Legion bilang anchor na 0 minuto bago, ayon sa sitwasyon sa iyong screen.

2) Mga Personal na Alarma (Custom na Timer at Paulit-ulit na Pagitan)

Maaari kang magrehistro ng walang limitasyong sariling custom na timer, gaya ng alarma sa pag-expire ng 30-minutong elixir, dungeon cooldown, at paalala sa pahinga.

🔍 I-click para palakihin
📷 Mga Setting ng Personal na Alarma (listahan ng custom na paulit-ulit na timer)
  • ＋ Idagdag: Magrehistro sa pamamagitan ng pagtatakda ng gusto mong pangalan, pagitan (sa minuto o takdang oras), at batayan ng pagsisimula.
  • Switch On/Off: Agad mong maibubukas o maisasara ang mga timer na kailangan mo lang gamit ang switch, at real-time na ipinapakita ang natitirang oras bago ang susunod na abiso.

3) Alerto sa Screen (Text Overlay Banner sa Laro)

Naglalagay ng teksto sa screen para madali mong makita ang mahahalagang abiso nang hindi hinaharangan ang tanaw mo habang naglalaro.

🔍 I-click para palakihin

  • Kopyahin ang Mga Error Lamang: Mula sa buong log, tumpak na kinukuha at inilalagay sa clipboard ang mga error (ERROR) at exception stack trace lang.
  • Pagkopya ng Napili: Sa text window, i-drag gamit ang mouse ang bahaging gusto mo at kopyahin lang ang bahaging iyon.

12 Mga Madalas Itanong (FAQ) at Paglutas ng Problema

T. Pinindot ko ang trigger key pero hindi lumalabas ang skill.

  • Tiyaking ang estado sa top bar ay Tumatakbo(kung na-click na ang▶ Start button).
  • Tiyaking naka-on ang macro enable switchng napiling slot, at may kahit 1 step man lang sa Sequence tab.
  • Kailangang nasa harap ng screen at naka-focus ang window ng laro ng Diablo IV.
  • Kung naka-pause ito sa pagbubukas ng chat o imbentaryo dahil sa pause key, pindutin ulit ang trigger key nang isang beses para ipagpatuloy.

T. Right-click ang gamit kong trigger key pero palaging nagsasara ang window sa imbentaryo o stash.

Sa Macro Settings, itakda ang Press Delaysa 250ms ~ 300ms. Sa ganitong paraan, ang 'maikling click' kapag nire-right-click mo para maglipat ng item ay direktang ipapasa sa laro, at tuma-on lang ang macro kapag matagal mong pinindot, kaya tuluyang mawawala ang maling pagsara ng window.

T. Hindi makita ng Stat Alteration gamit ang Horadric Cube ang button o humihinto ito.

Sa bersyon 1.30, malaki ang naging pagpapalakas sa logic ng OCR text recognition at sa pag-verify na walang laman ang cube. Maaaring mahirap ang pagkilala kapag sobrang malabo ang teksto sa graphics setting ng laro o sobrang labis ang UI scale, kaya kung magpapatuloy ang problema, sa folder na %APPDATA%\d4cute_helper\debug\ , kopyahin ang file na alter_slots.txt at itanong ito sa Telegram group.

T. Sa Stat Alteration, nagpapatong ang dalawang item o lumilipat sa susunod na slot nang walang pagbabago.

Sintomas ito na nangyayari sa PC na mabagal ang animation ng pagbabago. Sa tab ng mga convenience feature, taasan ang Paghihintay sa Resulta (ms)(hal. 3000 → 5000), at kung umuulit pa rin, i-upload sa group ang debug\alter_slots.txt . Mula sa 1.30.1, sinusuri nito kung walang laman gamit ang larawan ng unang slot ng cube at pinipindot ang Enter kahit huli lumabas ang accept window.

T. Saan ako magtatanong tungkol sa helper at macro?

Telegram user group @d4cute_helper lang ang tumatanggap. Ang YouTube channel na 삼촌안잔다잉 ay broadcast para mag-enjoy sa laro kaya hindi ito tumatanggap ng tanong tungkol sa helper at macro.

T. Pumuputi o kumikislap ang window (white-screen na pangyayari).

Inayos sa 1.30 ang puting screen sa pamamagitan ng pagpapalit ng renderer ng built-in browser. Kung lumitaw pa rin ito, i-upload sa Telegram group ang screen capture at ang resulta ng Kopyahin ang Mga Error Lamang sa log viewer.
