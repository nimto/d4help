1 처음 5분 — 설치부터 첫 매크로 가동까지

d4cute helper는 디아블로4 플레이 시 반복 스킬 시전, 버프 유지, 복잡한 인벤토리 호라드림의 함 선변성 작업을 쾌적하고 안전하게 보조하는 고성능 도우미입니다.

  1. 최신 설치본 다운로드 — 설치본(d4cute_helper_setup.exe)을 받아 설치하거나, 무설치 실행 파일(d4cute_helper.exe)을 바로 실행합니다. Windows가 "알 수 없는 게시자" 경고를 띄울 경우 추가 정보 → 실행을 누릅니다.
  2. 헬퍼를 켜면 창 크기가 자동으로 가장 작은 기본 크기로 시작되어 게임 화면을 가리지 않습니다.
  3. 프로필 줄에서 내 직업에 맞는 프로필을 선택하거나 ＋ 버튼으로 새로 생성합니다.
  4. 슬롯 A를 누르고 매크로 설정에서 파란색 발동키 버튼을 누른 뒤, 사용할 마우스 또는 키보드 키를 지정합니다.
  5. 시퀀스 탭에서 시전할 스킬 키와 딜레이를 추가하거나, 녹화 버튼을 눌러 실제 게임 플레이 키 입력을 그대로 기록합니다.
  6. 하단의 ▶ 시작 버튼을 누르고 게임으로 돌아가 발동키를 누르면 매크로가 안전하게 동작합니다.
🛡️
게임 창 활성화 감지: 헬퍼는 디아블로4 창이 활성화되어 있을 때만 키보드/마우스 입력을 게임으로 전송합니다. 바탕화면이나 다른 창 작업 중에는 자동으로 입력이 정지됩니다.
🖥️
게임 화면 모드: 디아블로4 화면 설정을 창 모드(전체 화면) 또는 창 모드로 두세요. 전체 화면(독점)에서는 오버레이가 보이지 않고 선변성의 화면 읽기가 실패할 수 있습니다.

2 최신 화면 구성 (v1.30)

1.30 판에서는 상단 바와 슬롯 탭 바가 한층 더 직관적이고 미려하게 업그레이드되었습니다.

🔍 클릭하여 확대
📷 d4cute helper 1.30 메인 화면 (A~G 7개 매크로 슬롯 확장 지원)

1) 상단 바 & 프로필 컨트롤

  • 실행 상태 표시기 — ● 중지됨 / ● 실행 중 / ● 일시정지 상태를 실시간 색상 점으로 표시합니다.
  • 상단 기능 버튼 — 업데이트(새 패치 감지 시 점멸), 설정(⚙), 테스트(⌨)(입력 전송 검증), 미니창 전환, 항상 위(핀), ···(추가 도구 메뉴).
  • 프로필 줄 (Profile Bar) — ‹ › 버튼으로 빠르게 프로필을 전환할 수 있으며, 콤보박스를 더블클릭하면 즉시 이름을 변경할 수 있습니다. ＋(새 프로필), ✎(이름 변경), 🗑(삭제), 텔레그램 로고, 문서(시즌 문서), ?(도움말) 버튼이 제공됩니다. 창은 켤 때마다 가장 작은 기본 크기로 뜨고(하한 900×700, 글꼴 배율에 따라 커짐), 전체창(최대화)은 없습니다.

2) 슬롯 줄 (Slot Navigation) — 7개 슬롯(A~G) 대폭 확장

  • A B C D E F G — 최신 패치를 통해 매크로 슬롯이 기존 4개(A~D)에서 총 7개(A~G)로 대폭 확장되었습니다! 복잡한 딜 사이클, 기동기, 보호막/버프 유지, 특정 상황 전용 스킬을 슬롯 부족 없이 넉넉하게 분리하여 등록할 수 있습니다. 켜진 슬롯은 테두리가 강조되고, 발동 중이면 붉은 바탕에 흰 글씨로 점등됩니다.
  • 매크로 이름 직접 지정 — 각 슬롯의 매크로 설정 화면에서 이름: [ 메인 매크로 ] 입력 필드를 통해 슬롯마다 직관적인 고유 명칭을 입력할 수 있습니다. 슬롯 버튼에 마우스를 올렸을 때 뜨는 툴팁 맨 위에도 이 이름이 크게 표시됩니다.
  • ♡ 후원 — "헬퍼는 무료입니다" 고지와 파트너 추천 링크(스타링크 등)·클랜장님 채널 소개가 배너 캐러셀로 나옵니다. 헬퍼가 자동으로 보내는 것은 없습니다.
  • 🔧 편의 — 호라드림의 함 인벤 선변성 자동화 전용 한 페이지 UI.
  • ⏱ ▶ 4 (알람) — 군단, 세계 보스, 지옥물결 및 개인 타이머 알람 설정. 우측에 현재 동작 중인 알람 수가 배지로 표시됩니다.
  • 슬롯 우측 요약 칩 — 현재 선택된 슬롯의 실행 방식(순차/독립), 발동 방식(홀드/토글/한 번), 발동키가 늘 실시간으로 요약 표시됩니다.

3) 하단 통합 제어 바

  • ▶ 시작 / ■ 중지: 헬퍼의 모든 매크로 감지 및 실행을 시작하거나 정지합니다 (기본 단축키 F9).
  • 저장: 현재 수정한 프로필 및 매크로 세팅을 디스크에 즉시 영구 저장합니다.
  • 📁 불러오기: 실수로 세팅을 잘못 건드렸을 때 마지막 저장된 상태로 프로필을 복원합니다.
  • ▶ 삼촌안잔다잉: 클랜장님의 게임 방송 채널로 한 번에 이동합니다.
  • 📤 내보내기: 현재 프로필 세팅을 .d4cute 백업 파일로 저장합니다.
  • 📥 가져오기: 다른 사용자나 클랜원이 공유한 .d4cute 프로필을 불러와 즉시 적용합니다.
  • 최소화: 헬퍼 창을 작업 표시줄로 최소화합니다.

3 매크로 설정 — 실행 방식 · 발동 방식 · 발동키

1) 실행 방식 및 발동 방식

구분 모드명 설명 및 추천 사용처
실행 방식 순차 스텝 1부터 마지막 스텝까지 순서대로 시전한 뒤 다시 처음부터 반복합니다. 정해진 스킬 콤보 및 딜 사이클 로테이션에 적합합니다.
독립 스텝마다 각자 설정된 쿨다운(대기 시간)에 맞춰 독자적으로 반복 실행합니다. 쿨다운이 제각각인 보호막/버프 스킬 유지에 최적화되어 있습니다.
발동 방식 홀드 발동키를 누르고 있는 동안만 매크로가 돌아가며, 키를 떼면 즉시 멈춥니다. 주력 딜링 스킬에 권장됩니다.
토글 발동키를 한 번 누르면 켜지고, 다시 누르면 꺼집니다. 장시간 파밍이나 던전 순회 시 손가락 피로도를 덜어줍니다.
한 번 발동키를 누르면 시퀀스를 1회 처음부터 끝까지 수행하고 스스로 종료합니다. 물약 연속 제작, 장비 구매 등에 적합합니다.

2) 발동키 선택 및 정밀 튜닝

  • 유연한 발동키: 키보드 모든 키, 마우스 좌/우 클릭, 휠 위/아래, 사이드 버튼, Ctrl · Shift · Alt 조합 키를 모두 지원합니다. 여러 슬롯에 동일한 발동키를 지정하여 동시 연계 발동도 가능합니다. 단, 편의기능(선변성) 시작 단축키와는 겹칠 수 없습니다 — 겹치면 고를 때 거부됩니다.
  • 누름 인식 지연 (Press Delay): 짧게 툭 친 클릭은 무시하고, 지정한 시간(예: 250~300ms) 이상 꾹 눌렀을 때만 매크로가 켜집니다. 우클릭을 발동키로 쓸 때 인벤토리나 창고 창이 닫히는 현상을 방지하는 필수 설정입니다.
  • 떼고 유지 (Release Buffer): 발동키를 손에서 뗀 후에도 지정한 시간 동안 매크로 동작을 연장 유지합니다. 사냥 직후 주변 바닥 아이템을 루팅하는 동안 공격이 끊기지 않도록 여유를 줍니다.
  • 동반 키 (Companion Keys): 매크로가 가동되는 동안 지속적으로 함께 눌러두는 키(예: 제자리 강제 정지 공격 Shift, 강제 이동 키 등)를 지정할 수 있습니다.

4 시퀀스 빌더 · 딜레이 일괄변경 · 마우스 녹화

1) 스텝 카드 및 일괄 조작

  • 스텝 카드를 클릭하면 키, 동작 모드, 딜레이(대기 시간, ms)를 개별 변경할 수 있습니다.
  • 모드 옵션:
    • Single: 키를 1회 단발 입력
    • Burst: 지정된 간격으로 고속 연타
    • Hold: 지정 시간 동안 키를 꾹 누르고 유지
  • 딜레이 일괄변경: 모든 스텝의 대기 시간을 원하는 수치(ms)나 비율(%)로 한 번에 변경합니다.
  • 전체 → Burst/Single: 모든 등록 스텝의 동작 모드를 원클릭으로 일괄 전환합니다.

📷 딜레이 일괄변경 팝업

2) Live mouse-position recording & humanized randomness

  • Press Record, then play in the game window: every key and mouse button is captured in order with its timing.
  • Screen coordinates: each mouse click stores the absolute screen position (X, Y) it was made at, and playback clicks that same spot.
  • Humanized randomness:
    • Click offset ± px: every click is nudged randomly within the given pixel radius.
    • Random variance %: every step interval gets a random delay within the given ratio.

3) Drag-path recording — the whole path while the button is held (1.32.0)

  • Move the mouse while holding a button during recording and the path is captured too: a point is stored whenever the cursor moves more than 8 px from the last point or 16 ms pass, so fast spins stay dense and slow moves stay continuous.
  • On playback the helper presses at the start point, follows the same path on the recorded timing, then releases at the end point. Earlier versions kept only the press and release points and jumped between them.
  • Channeled skills such as Whirlwind: bind the skill to the right mouse button in game, hold it and spin during recording, and the spin is recorded and replayed as is. Holding the left button while moving works the same way.
  • Random variance % is applied once to the whole path's duration and click offset ± px once to the whole path, so the cursor does not jitter.
  • Editing the position by number or pressing Clear drag in the step editor discards the path and falls back to the old jump playback.
  • Up to 600 points per drag (about 10 s at 16 ms). Paths are absolute screen coordinates: re-record after changing resolution or window position.

  2. 첫 칸 찍기를 누른 뒤 게임 인벤토리의 맨 첫 번째 칸(좌상단)에 마우스를 올리고 Enter를 누릅니다.

  4. 두 점의 위치만 지정하면 33개 인벤토리 칸의 중심 좌표가 자동으로 정확히 계산됩니다.

2) 동작 메커니즘 및 지능형 안전장치

  • 지능형 반복 루프: 인벤토리 각 칸을 순회하며 우클릭 → 호라드림 함에 올리기 → 아이템 변성 버튼 클릭 → 변환 → 수락(Enter) → 초기화를 자동으로 진행합니다.
  • 계정 귀속 아이템 건너뛰기 스위치: 스위치를 켜면 귀속 아이템은 건너뛰고 비귀속 장비만 골라 변성합니다. 스위치를 끄면 귀속 장비도 변성하며 수락 팝업 창이 뜰 때만 안전하게 Enter를 전송합니다.
  • 큐브 비움 검증 (Cube Empty Check): 초기화 뒤 큐브 첫 칸의 그림(첫 아이템을 올릴 때 빈 모습·찬 모습을 기억해 둠)으로 비었는지 보고, 그림을 못 잡은 환경에선 큐브 머리글 글자로 보조 판정합니다. 비지 않았으면 초기화를 다시 누르고, 끝내 안 비면 멈춥니다 — 아이템 두 개가 겹쳐 올라가는 일을 막기 위한 장치입니다.
  • 비상 정지: 작업 도중 키보드의 Esc 키를 누르면 어디서든 즉시 선변성이 멈춥니다.
  • 느린 PC 조절값: 시작 전 ms(시작 버튼 뒤 게임 창으로 갈 여유), 결과 대기 ms(기본 3000 — 변환·수락 뒤 변성이 끝나 변환 버튼이 꺼질 때까지 기다리는 상한, 신호가 오면 바로 넘어감), 초기화 뒤 ms(기본 0 — 초기화 뒤 추가 대기). 연출이 느린 PC 에서 아이템이 겹치거나 변성 없이 넘어가면 결과 대기를 올리세요.
  • 실행 기록: 한 바퀴 돌 때마다 %APPDATA%\d4cute_helper\debug\alter_slots.txt 에 칸별 판정이 남습니다. 문제가 나면 이 파일을 텔레그램 그룹에 올려 주세요.

  • 스마트폰 (모바일): 구글 플레이스토어 또는 애플 앱스토어에서 Telegram을 검색하여 무료 다운로드합니다. 전화번호 인증만 거치면 1분 만에 가입이 완료됩니다.
  • PC (데스크톱): Telegram Desktop ↗ 공식 페이지에서 Windows용 설치 버전을 내려받아 설치한 뒤, 모바일 텔레그램 앱의 설정 → 기기 → 데스크톱 연결을 통해 QR 코드를 스캔하면 비밀번호 없이 즉시 로그인됩니다.

삼촌안잔다잉 유튜브 채널은 디아블로4 게임 플레이와 소통을 즐기는 개인 방송 공간입니다. 유튜브 방송 채팅이나 댓글로는 헬퍼 문의를 일절 받지 않으니, 반드시 텔레그램 공식 그룹방(@d4cute_helper)으로 방문해 주세요.

📱 그룹방 간편 입장 방법 2가지

  • 방법 A (스마트폰 카메라 QR 스캔 — 가장 추천!): 스마트폰의 기본 카메라 앱을 켜고 화면 오른쪽의 대형 QR 코드를 비추면 상단에 노란색 텔레그램 링크 배너가 나타납니다. 터치 한 번으로 @d4cute_helper 그룹방에 즉시 들어오실 수 있습니다.
  • 방법 B (PC 텔레그램 바로 열기): 창에서 열기 버튼을 누르거나 웹 링크(https://t.me/d4cute_helper)를 클릭하면 PC 텔레그램 클라이언트로 직행합니다.

3) 로그 보기를 통한 오류 복사 & 문제 해결 방법

매크로가 갑자기 멈추거나, 선변성 도중 오류가 발생하거나, 예상치 못한 동작이 나타났을 때 제작자에게 상황을 설명하려면 로그 데이터가 가장 확실한 열쇠가 됩니다.

🔍 로그 뷰어 화면 구성 & 버튼 기능

  • 로그 일자 드롭다운: 오류가 발생한 날짜(기본: 오늘 날짜)를 선택합니다. 로그는 최근 7일간 자동 보관된 후 오래된 파일부터 순차 삭제됩니다.
  • 경고·오류만 토글 스위치: 수천 줄의 일반적인 INFO 로그를 숨기고, 시스템 경고(WARN) 및 오류(ERROR) 항목만 쏙 뽑아서 볼 수 있습니다.
  • 새로 고침: 헬퍼를 켜둔 상태에서 실시간으로 쌓이는 최신 로그를 즉시 화면에 다시 로드합니다.
  • 폴더 열기: 로그 원본 텍스트 파일들이 저장된 윈도우 탐색기 폴더(%APPDATA%\d4cute_helper\logs)를 직접 엽니다.
  • 최근 200줄 복사: 오류 직전까지 어떤 키가 눌렸고 어떤 이벤트가 일어났는지 맥락을 파악할 수 있도록 최근 200행의 로그를 클립보드로 복사합니다.
  • 오류만 복사: 로그 전체 중에서 오류(ERROR) 및 예외 스택트레이스 구문만 정밀 추출하여 클립보드에 담습니다.
  • 선택 복사: 텍스트 창에서 마우스로 원하는 부분을 드래그한 뒤 해당 구간만 복사합니다.
🛡️
개인정보 안심 보호 & 자동 전송 차단
  • 사용자명 자동 마스킹: 로그 안의 파일 경로(예: C:\Users\홍길동\...)에서 사용자 계정명은 자동으로 식별 불가능하게 숨겨져 복사되므로 사생활 노출 걱정이 없습니다.
  • 외부 자동 전송 차단: 하단 안내문("복사한 내용을 텔레그램 그룹에 붙여넣어 보내 주세요 — 헬퍼가 자동으로 보내는 것은 없습니다.")처럼, 헬퍼는 인터넷을 통해 사용자의 로그를 몰래 외부로 전송하지 않습니다. 오직 사용자가 직접 복사하여 붙여넣을 때만 안전하게 공유됩니다.

🚀 오류 로그 전달 및 신속 해결 3단계 가이드

  1. 1단계: 로그 복사하기
    문제가 발생한 즉시 텔레그램 다이얼로그에서 📁 로그 보기 버튼을 누르고, 창 하단에서 오류만 복사 또는 최근 200줄 복사 버튼을 클릭합니다.
    ※ 복사된 로그의 맨 첫 줄에는 헬퍼 버전, OS 환경, 해상도 배율 메타 정보가 자동으로 첨부되어 개발자가 환경을 단번에 파악할 수 있습니다.
  2. 2단계: 텔레그램 그룹방에 붙여넣기
    스마트폰 또는 PC에서 @d4cute_helper 그룹방으로 이동한 후, 메시지 입력창을 클릭하고 Ctrl + V(모바일은 입력창 길게 누른 뒤 붙여넣기)를 실행합니다.
  3. 3단계: 발생 상황 설명 덧붙이기
    로그와 함께 "어떤 상황에서 문제가 일어났는지" 1~2줄을 함께 남겨주세요:
    예시 1: "인벤 선변성 시작 후 12번째 칸에서 큐브 비움 검증 단계에서 멈춥니다. 로그 남깁니다."
    예시 2: "전역 설정에서 오버레이 위치를 바꿨는데 화면에 오버레이가 나타나지 않습니다."
    스크린샷이나 휴대폰 사진을 함께 첨부해 주시면 더욱 빠르고 정확한 진단과 패치가 이루어집니다.

12 자주 묻는 질문 (FAQ) & 문제 해결

Q. 발동키를 눌러도 스킬이 나가지 않아요.

  • 상단 바의 상태가 실행 중인지 확인하세요 (▶ 시작 버튼 클릭 여부).
  • 선택한 슬롯의 매크로 활성 스위치가 켜져 있는지, 시퀀스 탭에 스텝이 1개 이상 들어있는지 확인하세요.
  • 디아블로4 게임 창이 화면 맨 앞에 포커스되어 있어야 합니다.
  • 채팅이나 인벤토리를 열어 대기 키로 인해 일시정지된 상태라면, 발동키를 한 번 더 누르면 풀립니다.

Q. 오른쪽 마우스를 발동키로 쓰는데 인벤토리나 창고에서 자꾸 창이 닫혀요.

매크로 설정의 누름 인식 지연(Press Delay)을 250ms ~ 300ms로 설정하세요. 이렇게 하면 아이템을 우클릭해서 옮길 때의 '짧은 클릭'은 게임에 그대로 전달되고, 꾹 누를 때만 매크로가 켜져 창 닫힘 오동작이 완전히 사라집니다.

Q. 호라드림의 함 선변성이 버튼을 못 찾거나 멈춰요.

1.30 버전에서 OCR 글자 인식 로직과 큐브 비움 검증이 대폭 강화되었습니다. 게임 내 그래픽 설정에서 글자가 너무 흐리거나 UI 배율이 극단적인 경우 인식이 어려울 수 있으니, 문제가 지속되면 %APPDATA%\d4cute_helper\debug\ 폴더의 alter_slots.txt 파일을 복사하여 텔레그램 그룹에 문의해 주세요.

Q. 선변성에서 아이템 두 개가 겹치거나, 변성 없이 다음 칸으로 넘어가요.

변성 연출이 느린 PC 에서 생기는 증상입니다. 편의기능 탭의 결과 대기 ms를 올리고(예: 3000 → 5000), 그래도 반복되면 debug\alter_slots.txt 를 그룹에 올려 주세요. 1.30.1 부터는 큐브 첫 칸 그림으로 비었는지 확인하고 수락창이 늦게 떠도 Enter 를 칩니다.

Q. 헬퍼·매크로 질문은 어디서 하나요?

텔레그램 이용자 그룹 @d4cute_helper 에서만 받습니다. 삼촌안잔다잉 유튜브 채널은 게임을 즐기는 방송이라 헬퍼·매크로 문의를 받지 않습니다.

Q. 창이 하얗게 뜨거나 깜빡여요 (백화 현상).

1.30 에서 내장 브라우저의 렌더러를 바꿔 백화를 고쳤습니다. 그래도 다시 보이면 로그 뷰어의 오류만 복사 결과와 화면 캡처를 텔레그램 그룹에 올려 주세요.
