# 전리품 필터 공유

디아블로 4 의 **전리품 필터 코드**를 서로 올리고 받아 쓰는 공간입니다. 필터는 긴 문자열 하나라서 파일 없이 복사·붙여넣기만으로 주고받습니다.

## 필터 적용하기 (받은 코드 쓰기)

1. 아래 목록에서 쓰고 싶은 필터의 **코드 블록 오른쪽 위 복사 아이콘**을 눌러 전체를 복사합니다.
2. 게임에서 **전리품 필터** 창을 엽니다.
3. 필터 이름 칸 오른쪽의 **`⋯` 버튼**을 누르면 나오는 메뉴에서 **가져오기** 를 고르고, 복사한 코드를 붙여 넣습니다.
4. 규칙 목록이 들어오면 **`모두 사용`** 으로 켜고, 필요 없는 규칙은 체크를 꺼서 조절합니다.

> 코드는 중간에 줄바꿈이 들어가면 안 됩니다. 꼭 복사 아이콘으로 통째로 복사하세요.

## 내 필터 올리기

1. 게임의 전리품 필터 창에서 **`⋯` → 내보내기** 로 코드를 복사합니다.
2. **[전리품 필터 공유 이슈 만들기](https://github.com/nimto/d4help/issues/new?template=loot-filter-share.yml)** 를 열어 필터 이름 · 용도 · 코드를 적습니다(GitHub 로그인 필요).
3. 올린 필터는 [전리품 필터 이슈 목록](https://github.com/nimto/d4help/issues?q=label%3A%22전리품+필터%22) 에 바로 보입니다. 관리자가 확인한 것은 아래 표에도 등록됩니다.

## 알아 둘 점

- 전리품 필터는 **게임 기능**입니다. d4cute helper 와는 별개이며, 헬퍼를 쓰지 않아도 적용할 수 있습니다.
- 필터는 바닥에 떨어진 아이템의 **표시 방법만** 바꿉니다. 아이템이 사라지거나 성능이 달라지지는 않습니다.
- 숨김 규칙이 들어간 필터는 필요한 아이템까지 가릴 수 있습니다. 적용한 뒤 한 번 돌아 보고 규칙 체크를 조절하세요.
- 시즌이 바뀌거나 게임 업데이트가 있으면 예전 코드가 그대로 들어가지 않을 수 있습니다. 그럴 때는 이슈로 알려 주세요.
