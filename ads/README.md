# ads — d4cute 헬퍼 [후원] 탭 광고 페이지

헬퍼의 **[후원]** 탭은 이 폴더의 `index.html` 을 자체 브라우저로 띄웁니다.
배너 캐러셀(한 화면, 창 크기를 따라 커짐) + 배너를 누르면 아래에 상세(영상·쓰임새·요금·출처).
주소: <https://nimto.github.io/d4help/ads/>

- `index.html` — 레이아웃·스타일·그리는 스크립트. 광고를 더할 때는 건드리지 않습니다.
- `ads.js` — **광고 목록**. 항목 하나 = 배너 한 장. 여기만 고치면 헬퍼를 다시 빌드하지 않아도 바뀝니다.
- 스크롤은 되지만 스크롤바는 숨겨 둡니다(헬퍼 창 안에서 한 몸처럼 보이게).
- 링크는 전부 `target="_blank"` — 헬퍼 안에서는 기본 브라우저로 열립니다.

## 광고 추가하기

`ads.js` 의 배열에 항목을 하나 더 넣습니다. 순서가 화면 순서입니다.

```js
{
  id: "partner-id",            // 영문 소문자·하이픈. 카드의 HTML id 가 된다
  active: true,                // false 면 숨긴다 (지우지 않고 내릴 때)
  partner: "파트너 이름",
  category: "한 줄 분류",       // 예: 위성 인터넷
  accent: "#7dd3fc",           // 카드 상단 띠 색 (파트너 브랜드 색). 없으면 금색
  title: "카드 제목 (한 문장)",
  lead: "두세 문장 소개. 과장 없이, 누구에게 왜 좋은지.",
  videos: [                    // 유튜브 영상. 첫 번째가 기본, 둘 이상이면 칩으로 전환
    { id: "유튜브ID", label: "칩에 보일 이름", meta: "채널 · 길이" }
  ],
  points: [                    // 쓰임새 격자 (3~5개)
    { h: "제목", p: "설명" }
  ],
  facts: [                     // 요금·사양 표 (없으면 빼도 된다)
    { k: "항목", v: "값" }
  ],
  factsNote: "기준일과 '공식 사이트에서 확인' 안내",
  cta: { label: "버튼 글자", url: "추천 링크" },
  code: "추천 코드",            // 상세의 버튼 아래 작은 줄에 보인다 (없으면 빼도 된다)
  disclosureShort: "배너에 보일 한 줄 고지",   // 없으면 disclosure 를 쓴다
  thumb: "https://...jpg",     // 배너 썸네일. 없으면 첫 영상의 유튜브 썸네일
  kind: "recruit",             // 파트너 모집 같은 글자만 있는 슬라이드 (영상·상세 없음)
  disclosure: "추천 링크 고지 - 보상이 갈 수 있고 가입자 추가 비용은 없다는 한 줄",
  sources: [ { label: "출처 이름 · 날짜", url: "..." } ]
}
```

### 유튜브 영상 ID 찾기
주소 `https://www.youtube.com/watch?v=XXXXXXXXXXX` 에서 `v=` 뒤 11자리가 ID 입니다.
임베드를 막아 둔 영상은 플레이어에 "재생할 수 없음" 이 뜨니, 넣기 전에 브라우저에서
`https://www.youtube.com/embed/XXXXXXXXXXX` 를 열어 재생되는지 한 번 확인합니다.

### 지키는 것
- 추천 링크면 **고지 한 줄**(`disclosure`)을 꼭 넣습니다.
- 요금·수치는 **기준일**과 **출처**를 적습니다. 최신 값은 공식 사이트로 안내합니다.
- 타인의 영상은 유튜브 임베드로만 싣습니다(파일 복사 금지).

## 배너에 보이는 것
제목 · 리드(3줄까지) · `points` 앞 3개의 제목 · CTA · `disclosureShort` · 첫 영상 썸네일. 나머지(영상 전환·쓰임새 전부·요금·출처)는 배너를 눌렀을 때.

## 확인
고친 뒤 푸시하면 GitHub Pages 가 1~2분 안에 반영합니다. 헬퍼에서는 다른 탭을 눌렀다가
[후원] 탭을 다시 누르거나 헬퍼를 다시 켜면 새 내용이 보입니다.
