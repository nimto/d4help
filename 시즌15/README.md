## 읽을 때 참고

- 블리자드 공식 글을 1 순위로 썼고, 커뮤니티(인벤·kakao.gg 등) 정보는 본문에 **커뮤니티** 라고 표시했습니다. 확인하지 못한 수치는 **미확인** 으로 남겼습니다.
- 문서마다 **이미지와 영상**을 넣습니다. 이미지는 블리자드 공식 자료를 링크로 참조하고(저장소에 복사하지 않음), 영상은 YouTube 썸네일을 누르면 열리는 방식입니다(GitHub 는 영상 직접 재생이 안 됨). 본인 스크린샷을 올리려면 `시즌15/images/` 에 넣고 문서에서 상대 경로로 링크하세요.
- 게임 패치로 바뀔 수 있습니다. 각 문서 머리의 "최종 갱신" 날짜를 보세요.
- 틀린 내용·추가 요청은 [GitHub Issues](https://github.com/kaljake70/d4helper/issues) 로 알려 주세요.
