# D4 Help

디아블로4 클랜 헬퍼 배포 공간. 항상 **최신 버전**만 내려받을 수 있습니다.

## 최신 버전 다운로드

아래 링크는 언제나 가장 최신 릴리스로 연결됩니다.

**▶ [최신 헬퍼 다운로드](https://github.com/nimto/d4help/releases/latest)**

- 위 링크를 열면 최신 릴리스 페이지가 나오고, 하단 **Assets**에서 헬퍼 파일을 받습니다.
- 고정 다운로드 주소(파일명이 일정할 때):
  `https://github.com/nimto/d4help/releases/latest/download/<헬퍼파일명>`

## 설치 / 사용

1. 위에서 최신 헬퍼 파일을 받습니다.
2. 압축이면 풀고 실행 파일을 실행합니다.
3. 자세한 사용법은 릴리스 노트를 참고하세요.

## 안내

- 이 저장소는 **배포 전용**입니다. 소스 코드는 비공개로 별도 관리됩니다.
- 새 버전이 나오면 최신 릴리스로 교체됩니다. 항상 위 "최신 다운로드" 링크를 사용하세요.
